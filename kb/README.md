# kb/ — 你的私有知识库（自建目录）

本目录是**空位**：仓库不附带任何往届题解、论文或官方材料（版权与合规原因）。
请在这里放**你合法持有**的内容，并让它服务你的备赛/复盘流程。

## 建议结构

```
kb/
├── topics/         # 题源与题面（你自己的整理，注明来源与公开链接）
├── methods/        # 方法笔记（按模型族归档：优化 / 预测 / 评价 / 图论 / 仿真 …）
├── notes/          # 复盘笔记、失败案例、可复用片段
└── index.md        # 目录索引（一页看全，便于 agent 渐进加载）
```

## 使用约定的三条

1. **来源标注**：每条材料写清来源（公开链接 / 自撰 / 授权范围）。未标注的不要入库。
2. **三态标注**：结论标 `[事实] / [推断] / [假设]`——尤其从题解里推出的经验。
3. **一页索引**：`index.md` 只放指针与一句话摘要；正文分文件，避免单文件过大。

## 与工作流的关系

| 场景 | 入口 |
|---|---|
| 选题与读题 | `workflows/02-选题与读题.md` → 在 `kb/topics/` 找相似题 |
| 建模选型 | `workflows/04-建模.md` → 在 `kb/methods/` 找可选模型族 |
| 复盘归档 | `workflows/09-知识管理.md`（含**提炼机制**：候选 → 复核 → 落盘） |

> 目录内容默认不入 git（见根目录 `.gitignore`：`kb/*` 已被忽略）。
> 想版本化自己的知识库，请另建私有仓库，不要提交到这里。
