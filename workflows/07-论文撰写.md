## 摘要（最最关键，优先写）

⚠️ 冷水③：摘要写砸直接降档。评委先看摘要。

摘要必须包含五要素（评委按此打分）：
1. **问题**：一句话说清解决什么问题
2. **方法与解决过程**：点名核心模型；每个问题一句"假设 → 方法 → 求解方式"；含问题间衔接（沿用/修正/拓展，见下节）
3. **结果**：关键数据结果（具体数字 + 单位）
4. **检验**：一句话说敏感性/检验结论
5. **结论与改进点**：结论 + 相对基线或朴素做法的量化优势（比什么、好多少）

**先写摘要，再写正文**——摘要写清楚了，正文结构自然出来。摘要通常最后再精修。

### 摘要逐句骨架（直接填空）

**国赛版（一页）**：
1. 〔背景+问题〕针对……问题，本文建立了……模型。
2. 〔对每个子问题重复〕针对问题一，在……假设下，采用……方法，求得……（**必带具体数字结果**，如"最优成本为 80792 元"）；问题二起用衔接语："基于问题一的结果，将模型修正/拓展为……，求得……"。
3. 〔检验〕通过敏感性分析，结果表明……对……稳健/敏感。
4. 〔结论+改进点〕本文模型相比……提升/改进了……（量化），为……提供了决策依据。

**美赛版（Summary Sheet，一页）**：
1. One sentence: the problem and why it matters.
2. For each sub-problem: we formulate/apply [model] to obtain [key numeric result]; from the second task on, state the linkage ("building on Task 1's output, we extend the model to ...").
3. We validate our model via sensitivity analysis, showing [robust / sensitive to X].
4. One sentence: strength of the approach (quantified advantage over baseline) and the recommendation.

**硬性要求**：结果句没有具体数字 = 摘要不合格，重写；整篇摘要至少体现一处量化改进（比什么、好多少）。

## 论文结构（标准）

```
摘要
一、问题重述
二、问题分析
三、模型假设
四、符号说明
五、模型建立与求解（核心，按子问题分节）
六、模型检验与敏感性分析
七、模型评价（优缺点+改进）
八、参考文献
附录（代码）
（AI 使用声明——位置以官方规定为准）
```

**两种组织方式均可，选一种贯穿全文**：
- A. **按问题**：每个问题一节，节内含"分析 → 假设（增量）→ 模型 → 求解 → 检验"
- B. **按阶段**：建模 → 求解 → 检验，每阶段内部按问题展开
章节编号风格统一（依模板），各节对应哪个子问题一目了然；不得两种混用。

## 问题间衔接（问题 2/3/4 沿用前面问题时必须写清）

三种衔接形式，措辞对号入座；禁止三个问题三套互不相干的模型：
- **沿用**："问题二的模型沿用问题一的 X 模型，假设与符号全部继承，仅将输入替换为……"
- **修正**："问题二在问题一模型基础上引入……（新约束/新机制），修正了……假设，其余不变"
- **拓展**："问题三将问题一模型从二维拓展到三维 / 从静态拓展到动态 / 从单目标拓展到多目标，新增……"

写作要点：
- 每个问题的节首写一句衔接说明（沿用什么 / 修正什么 / 拓展什么）
- 问题分析节给出子问题数据流图（来自 problem-decomposition 拆题）
- 摘要同样体现衔接（见五要素第 2 条）

## 图表规范

- **硬性要求：所有论文图表必须经 `templates-library/utils/plot_style.py` 统一输出**（`style_plot()` 统一风格，`add_units()` 加单位）——全文图风格不统一是显性扣分点，禁止裸 matplotlib 默认样式出图；**完整图件管线（Figure Contract 四步/双赛事风格/交付三闸：audit_fig+figcheck+主模型 vision）见 `references/图件管线.md`**（2026-09-19 建立）
- **编号与表题**：图"图 1、图 2…"连续编号，**图题在图下方**；表"表 1、表 2…"连续编号，**表题在表上方**，三线表
- **每个图表必须在正文中被引用**（"如图 3 所示"），不允许孤图孤表
- **要素齐全**：图例、坐标轴标签 + 单位、误差棒；字号缩印后仍可读；曲线灰度打印可区分
- **禁止模糊截图 / 无标注图片 / 代码运行截图**；用矢量图（PDF）或 ≥300dpi
- 图注英文（美赛）/ 中文（国赛）；措辞与符号表一致
- 图表能自解释：看图不看正文能懂

## 语言

- 美赛：全英文，术语准确，避免中式英语
- 国赛：全中文，规范书面语

## 参考文献（按各竞赛规则用适配格式）

- **国赛 CUMCM**：按 **GB/T 7714-2015**（顺序编码制；专著/期刊论文/学位论文/电子资源著录格式不同，注意区分）
- **美赛 MCM/ICM**：COMAP 不强制单一格式，但**全文一种风格**（数字制或 author-year），数据集、软件也须注明来源与版本（版本可放附录）
- 正文引用与文献表一一对应：引了没列、列了没引都不行
- **非学术来源禁入**：CSDN、知乎、百度百科、博客园等不进参考文献
- AI 工具按 10-AI使用声明列入参考文献；AI 引用不替代真实文献

## 行文逻辑（推理链闭环）

- 全文主线：问题分析 → 假设 → 模型 → 求解 → 检验 → 结论，前后呼应（问题分析里说"将在第 X 节解决"的，后文必须兑现）
- 章节间有过渡：上一节末段预告下一节解决什么；新节首段说明"本节要解决什么"
- **不引用后文**：不出现先引用后文图表/公式/结论的情况
- 每个图表后有讨论（"为什么是这个结果"），不停在"结果如图所示"
- 术语全文一致：一个概念一个词（见 de-ai-writing.md 优雅变体）

## 去 AI 化（用户要求 + 深度方法论）

AI 参与写作时，最终文本须：
1. 队员本人重写核心论述（铁律⑤，竞赛规则）
2. **逐条过「八类 AI 痕迹」清单**——过度强调词（标志着/重要）、广告语（突破性）、模糊归因（研究表明/专家认为无出处）、空洞"展示了/反映了"、公式化"挑战与展望"、"三法则"（原因有三/不仅…而且）、"此外"滥用、同义词循环（模型/算法/方法混用）
3. **结果描述铁律**：每句至少含 ①具体数字 ②具体对比 ③因果解释 之一
4. **注入真实感**：对意外结果给解释、局限要落到本次建模的具体选择（附边界条件）
5. 英文（美赛）专项：moreover/furthermore ≤2 次、禁 notably/crucially/intriguingly、全文 em dash ≤2、结尾段必须含数字+具体局限
6. 全程记录 AI 使用（见 10-AI使用声明）

> 📥 深度参考（逐句自查时读）：`references/获奖级方法论/de-ai-writing.md`——完整禁用词表 + 改写前后对比 + 中英快速自检清单（13KB 全文）。

## 格式细节（低级错误零容忍）

- 页码连续、位置依模板；页眉依竞赛模板（mcmthesis 自带控制号页眉），不自行增删
- 行距、页边距依模板，不自行改动
- 公式编号右对齐，正文引用为"式(3)"；符号与符号表一致
- 图片靠近首次引用处，避免大片空白与图题跨页截断（LaTeX 浮动 [H]/[htbp] 合理使用）
- **附录排版**：核心代码摘录 + 一行注释（输入/输出），禁止整屏截图堆砌；超长代码按竞赛规则放支撑材料或列可运行文件清单
- 交卷前：编译一次导出 PDF，逐页检查图缺失、乱码、表格跨页断行、溢出
