# 共享规范（各工作流通用）

> 所有工作流引用本文件的对应章节，不重复定义。
> **中性声明**：本产品不依赖任何特定 agent / CLI / 调度器；文中「会话 / 独立上下文」均指「任一次可复算的执行单元」，可由人或任意工具承担。

## 1. 质量门禁

### 1.1 正式交付物（完整论文 / 成套求解 / 模拟赛作品 / 答辩材料）

| 门禁 | 检查内容 | 未通过处理 |
|------|---------|-----------|
| 自查 | 对应工作流 checklist 逐条过 | 补齐 |
| 模拟评委审查 | 按最高档标准找扣分点 | 修复后重审 |
| 决策日志 | 关键决策（选题 / 模型选择）记录 | 补记 |
| 溯源检查 | 数据 / 模型 / 引用是否标注来源 | 补标 |
| 三态标注 | 事实 / 推断 / 假设区分 | 补标 |

交付物头部附自查说明：`[自查] 已通过XX工作流checklist，模拟评委发现N个扣分点，已修M个，待讨论K个`。

### 1.2 日常任务（单次问答 / 改代码 / 跑脚本 / 格式）

轻量：三态标注 ✓ + 溯源 ✓；模拟评委 / 决策日志不做；`learnings.md` 仅在踩坑时追加。

### 1.3 流程硬门禁（防越级 · 执行纪律借鉴公开建模技能库，来源见 THIRD-PARTY.md）

按顺序执行，任一未完成不得进入下一步：

1. **题目未解析完**（目标/对象/约束/数据/输出/可检验结论明确）→ 不进模型选择
2. **模型未选定 / 理由未记录** → 不写代码
3. **没有结果 artifact**（代码跑出的数字 / 图）→ 不写带具体数字的论文结论
4. **没有敏感性 / 稳健性检查** → 不声称「模型更优」
5. **不修改原始数据**；不编造数据 / 数值 / 参考文献 / 实验 / 性能结论
6. **ML 任务必须先完成数据集划分**（监督学习：训练 / 验证 / 测试或 K 折方案，划分先于预处理防泄漏；聚类等无监督任务不划分，改用轮廓系数 + 多次重跑稳定性检验）→ 才允许训练并报告性能
7. **没有同条件基线对照数据** → 不写「改进算法 X 优于 Y / 融合模型优于单模型」类改进主张（可复现优先；改动说明 + 基线对照 + 量化效果，缺一不可）

## 2. 模拟评委审查（对抗性审查）

提交前执行，维度：

| 维度 | 检查问题 |
|------|---------|
| 摘要 | 是否含五要素（问题 / 方法与解决过程 / 量化结果 / 检验 / 结论与改进点）？问题间衔接体现了吗？30 秒能看懂吗？ |
| 假设 | 每条假设有现实依据吗？与数据矛盾吗？ |
| 模型 | 选型合理吗？是必要的还是堆砌？做深了吗？ |
| 求解 | 结果可复现吗？收敛了吗？精度够吗？ |
| 检验 | 敏感性分析做了吗？换参数结果稳健吗？ |
| 结论 | 结论超出数据 / 模型范围了吗？ |
| 图表 | 图表能自解释吗？有单位吗？ |
| 合规 | AI 声明齐了吗？引用规范吗？ |

每条扣分必须附改法。

> 📥 **评委审查增强（CE 声明）**：正式审查时读 `references/获奖级方法论/self-review-framework.md`——用 **Claim-Evidence（CE）映射表**（模板 `templates/Claim-Evidence映射表.md`）逐条核验每个核心主张是否有证据（✅ / ⚠️ / ❌），**❌ 主张当场打回补证据**、禁止进入下一轮；「CE 映射无 ❌ 主张」是论文装配线（E-M7）的放行条件之一。

### 2.1 评分权重表（模拟评奖统一口径 · 防打分漂移）

| 维度 | 权重 | 打分要点 |
|------|------|---------|
| 摘要 | 25 | 五要素齐全、有关键数字、30 秒看懂 |
| 模型 | 25 | 选型合理、做深不堆砌、假设支撑 |
| 检验 | 15 | 敏感性分析 + 模型检验到位 |
| 图表写作 | 15 | 图表自解释带单位、语言规范、逻辑链完整 |
| 求解 | 10 | 可复现、收敛、精度合理 |
| 假设 | 10 | 有依据、数量合理、与现实一致 |

> ⚠️ 权重为**现行默认值**（经验值，须自行重校）；任何权重 / 判档线变更须记 changelog。**再现「连续 2 篇跨级判错」→ 评审端自触停用复校**。锚校准 / 评审进化机制见 §2.3。

> 📎 **T（检验）维口径**：方法互验（两法交叉复算 / 闭式验证）、特例与边界检查、博弈闭式解均**计入 T**；总分距判档线 ≤1 分（贴档）时必须标注「贴线敏感」。

> 🧭 **评分协议（<校准标准>）**：判档 = 六维总分 → 结构帽 → M 门槛 → 贴档双评。①**最高档** total ≥76 且 M≥20；第二档 70–75 且 M≥18；次低档 60–69；最低档 ≤59。②**结构帽（只封顶）**：C1 摘要无可点名数字→A≤18；C2 无互验/特例/闭式→T≤10；C3 无复现材料→S≤8；C4 堆模型无对照→M≤17。③**低档帽**：双评后 M_final ≤15 → 判档不得高于最低档（总分落次低档带则强制降档）。④**贴档双评**：总分落 60–65 / 68–72 / 74–75，或门槛未过（≥76 且 M≤19 / 70–75 且 M≤17）→ 第二遍**隔离上下文**独立评分（只看判准 + 帽、后看第一评；跨档 → 第三评或「边界不确定」）。⑤**模糊档位标签**（如「优秀汇编」）不计入正式命中：验证集只收明示档位样本。⑥以上阈值全为**经验值，必须用你自己的锚重校**（规程见 `references/scoring-rubric.md` §5.1）。全文正本：`references/scoring-rubric.md`。

输出格式：`总分 /100 + 各维度得分 + 扣分点（附改法）+ 预估档位（O/F/M/H 或 国一/国二/省一）+ 贴线余量标注`。

> 🔧 **判分前置脚本预检**：判分 / 自审会话开始前先跑 `python scripts/precheck_paper.py <材料> --profile our`（我方材料）或 `--profile ref`（参考样本）；**预检输出必须附入判分会话的「预检裁决」小节**（逐项 OK / WARN / FAIL 与处理）。
> 📐 **贴线余量字段（强制）**：逐件给出 `余量 = |总分 − 最近判档线|`；余量 ≤1 分 → 标注「**贴线敏感**」；每批输出**必须带有效批号**；样本扩充前禁止称判档线为「稳定常数」。记录模板见 `<校准台账>`。

### 2.2 修复动机审计

**分数 / 档位是副产品，材料更真实、更可复现才是目标。** 每条扣分修复落盘前必过三问：

1. **独立依据**——有数学正确性 / 求解证据 / 竞赛规则层面的依据吗？
2. **可证伪性保持**——评委复算 / 复跑仍能暴露真实缺陷吗？无敏感性数据支撑的「换参数就稳了」= 掩盖。
3. **如实报告不变式**——不收敛 / 不理想的结果写进模型评价，不是删除；不编造、不美化摘要关键数字。

红旗五类命中即禁落盘（堆砌高级模型名词充创新 = 纸面通胀的形态）。

### 2.3 评审进化链路（记录正本 = `<校准台账>`）

- **缺陷谱系扫描**：提交前自查并入台账七族（摘要空洞 / 模型堆砌 / 改进通胀 / 敏感性缺失 / 图表缺陷 / 结果-代码脱钩 / AI 声明漏填）。
- **outcome 锚**：备赛期 / 复盘时先抽 1 篇**已知档位**样本（注册卡模板 `templates/锚注册卡模板.md`）盲评判档 → 与实际档位对照；**连续 2 篇跨级判错 = 评审端重校**。**赛中跳过**。
- **盲区轮换**：连续 2 场同一评分维度零新发现 → 换命题视角；预判档位连续 2 场上升 → 必须报告锚判档记录自证未放水。
- **独立复现闸门**：对**我方材料的自评分不得直接作交付质量依据**——重要定稿（模拟赛提交版 / 复盘结论文本）须另开**全新上下文**盲评一遍：自评与盲评分差 >5 分（百分制，**经验值，须自行重校**）→ 分歧逐条解释并整改；盲评抓出的高危缺陷未闭合 → 一票否决定稿。**赛中跳过**。
- **标准版本化**：<校准标准>-vN.M，权重表 / 判档线变更记 changelog。

> 时间盒见 `<校准台账>` §时间盒。自评系统性偏松是常见现象，须用自己的样本实测确认，不得沿用他人偏置值。

**生成侧校准（与本节评审端分离）**：生成锚 / 尺子校准 / 泄漏审计**仅备赛期 / 复盘执行，赛中（72–96h）禁止**——正本 `<校准台账>`。

| 阶段 | 时间 | 目标 | 冲刺节点动作 |
|------|------|------|------------|
| 选题 | 前 6h | 读完 6 题，定方向 | 建决策日志 + AI 记录表 |
| Day1 | 0-24h | 问题拆解、假设、首版模型 | 24h 末补 AI 记录表 |

| Day3 | 48-72h | 检验、优缺点、论文主体成形 | 72h 末补 AI 记录表 |

**原则**：先保证完整性（有模型有结果有论文），再追求深度。倒计时里砍范围不砍深度。

## 经验教训（已提炼）

> 来源 `learnings.md`；入选门槛：同主题复发 ≥2 次。条目只增不改，被证伪时原位补「[已证伪]」说明。

### LS-1 自报口径必须与逐条实点互核

- **现象**：同一批数据的「头部汇总数字」与「逐条清单实点」不一致——汇总时混淆了样本集定义（独立集 / 全库集 / 含复评集），把非独立件混入统计。
- **根因**：汇总数字靠人工转录而非脚本直出。
- **执行要求**：
  1. 交付件中的**汇总类数字**（n、命中率、覆盖率、分差）必须由脚本直出，禁止手工转录；
  2. 交付前逐项复点：把报告中的每个数字回到**原始逐条清单**上数一遍，数目不符即阻断交付；
  3. 样本集必须**先定义后计数**——多种集合口径并存时，每个数字后强制标注集合名。

### LS-2 正本哈希全绿 ≠ 行为层一致

- **现象**：文件的哈希校验全部通过，但行为层（实际执行口径）仍不一致——关键规则表头缺停用 / 现行状态警示，同一规则在多份副本里表述不一。
- **根因**：哈希只证明**字节未被改动**，不证明多份副本间的语义等价，也不证明运行时读取的那一份是权威版本。
- **执行要求**：
  1. 校验分两级——① 哈希级（字节未变）② **行为级（逐文件 diff，确认同一规则在各副本中的表述一致且警示在位）**，两级都过才算一致；
  2. 关键规则（权重、判档线、停用状态）必须**单点正本 + 编号引用**，禁止在多处复述具体数值；
  3. 改这类规则时，同步 **台账 / 注册卡 / `_SHARED` / 报告** 四处，缺一处即视为未完成。

### LS-3 样本集纪律：自证样本不得用于解锁

- **现象**：用被评样本自身的同批数据提出规则重构（自证循环）；判分臂与生成臂同源，系统性偏差未消解。
- **根因**：用 A 得出的结论去验证 A，证据链闭环在自身内部，无法排除系统性偏差。
- **执行要求**：
  1. **独立验证集是唯一解锁证据源**——任何机制的有效性结论只认独立样本；自证样本可作线索，**不得**作放行依据；
  2. 结论报告必须含**构成注记**（哪些是独立样本、哪些是复评件 / 自证件），不得只报合并数字；
  3. 样本量未达线时明确标注「卡线不放行」，不因「趋势向好」提前解锁；
  4. 判分臂与生成臂**物理隔离**（禁读判准表 / 独立子会话 / 白名单读取），执行日志与自报读取次数双核。

## 5. 人机分工

| 角色 | 代号 | 含义 |
|------|------|------|
| 人 | 人 | 必须由队员完成，AI 不可替代 |
| 审 | 审 | AI 生成 / 执行，人审阅确认 |
| 自 | 自 | AI 自主完成，人看结果 |

**不可替代项（标记"人"）**：
- 最终选题决策
- 模型假设拍板
- 核心建模与分析（竞赛规则要求独立完成）
- 论文最终文本确认
- 提交前终审

## 6. 三态标注

| 标注 | 含义 |
|------|------|
| [事实] | 有出处 / 可核验的数据、结论 |
| [推断] | 基于事实的合理推断 |
| [假设] | 未经验证的猜测（建模假设本身就是 [假设]，但须论证依据） |

## 7. 认知偏见检查点

建模 / 数据分析时主动提醒：确认偏见、选择性报告、幸存者偏差（获奖论文 ≠ 正确做法）、锚定、沉没成本（模型跑不通要及时换）。
