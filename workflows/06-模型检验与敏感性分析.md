## 敏感性分析（必做，评委标配追问；不是走形式）

**核心问题：换个参数，结果还成立吗？**

**第 1 步：选 2-4 个核心参数**（不撒网全扫），入选标准（满足任一）：
- 拟合得到或经验估计的参数（不确定性大）
- 支撑关键假设的参数（一动摇就动摇模型根基）
- 预实验中输出梯度大的参数

题目精确给定的常数、物理常数不扫。

**第 2 步：先定判定标准**（跑之前写下，禁止事后美化）：
- 例："扰动 ±20% 时输出变化 >10% 判为敏感；≤10% 判为稳健"
- 每个参数直接给定性结论（敏感/稳健），禁止"鲁棒性良好"这类模糊话

**第 3 步：OAT 扰动扫描**（±10% / ±20%，扩展范围按参数含义定）：
- 用 `utils/sensitivity.py`：`scan_1d` 单参数曲线、`scan_2d` 双参数热图、`tornado` 多参数龙卷风图
- **扫了几个参数就呈现几个**，禁止只挑好看的；参数相关时补双参数扫描（scan_2d）
- 冲 O 奖/国一可选升级：`sobol_indices`（Sobol 全局敏感性，SALib），给出一阶/总阶指数，处理参数交互——时间紧时 OAT 足够，不做不写

**第 4 步：如实下结论**：
- 稳健 → 说明在哪个范围内稳健
- 敏感 → 给出敏感程度（数字），给缓解手段（重新标定/鲁棒优化）或列为局限
- 对齐台账动机审计红旗⑤："无敏感性数据支撑的稳健性口头承诺 = 掩盖"

## 模型检验（按题型选合适的做，≥2 种）

| 检验方式 | 适用 | 要点 |
|---------|------|------|
| 特例验证 | 通用 | 已知解/退化情形/对称情形 |
| 对比验证 | 通用 | 与已有方法/文献结果/朴素基线对比 |
| 拟合检验 | 回归/拟合 | R²、调整 R²，拟合曲线叠散点图 |
| 残差分析 | 回归/拟合 | 正态性（QQ 图）、方差齐性、自相关；残差图无漏斗形/弯曲 |
| 交叉验证 | ML/预测 | K 折（K=5），纪律按 05 ML 任务章节 |
| 鲁棒性测试 | 通用 | 数据扰动（加噪/删样本）、假设放松，看结论是否翻转 |
| 收敛性检查 | 仿真/迭代算法 | 重复次数/代数 vs 指标稳定性 |

**选型指引**：预测/回归 → 拟合检验 + 残差分析 + 交叉验证；分类/ML → 交叉验证 + 混淆矩阵/AUC；优化 → 特例验证 + 界检查 + 扰动重解；评价 → 权重敏感性 + 序反转检查；仿真 → 收敛性 + 与真实值对比。**写了什么就做了什么，做了什么就写什么**——没做的检验不写，做了的检验不漏。

## 优缺点评价（论文必备段落，客观书写）

- 优缺点必须针对**本模型的具体选择**（做了什么假设、用了什么算法），禁止"模型简单易懂、实用性强"这类通用套话
- 每条缺点对应一条改进方向（具体可做，不是"未来再研究"）
- 缺点的数量和严重程度如实反映；评委看的是可信度，不是缺点数量

⚠️ 冷水②：重结果轻过程。没有敏感性分析和检验的论文在中高分段掉档。

## 误差/不确定性讨论

- 模型误差 vs 数据误差，哪个主导
