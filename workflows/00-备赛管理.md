## 训练循环（核心）

```
学模型(概念页+代码模板) → 做真题(限时) → 模拟赛(全流程) → 复盘(learnings+KB) → 沉淀(拆解入KB)
```

## 每周节奏（建议）

- 平时：1 个模型方法 + 1 道对应真题
- 周末：1 次限时训练（2-3h 做一题的建模+求解骨架）
- 每月：1 次完整模拟赛（72h 或压缩版）

## 生成锚纪律（2026-09-18 新增 · 任务书 v1.5 §1.3.2-6）

- 生成侧校准（生成锚 / M-plan 尺子校准 / L1–L6 泄漏审计）**全程为备赛期活动**，纳入评审台账 §五「备赛期/复盘」口径。
- **赛中（72–96h）禁止跑生成锚**（不拖慢铁律）。执行入口：`Euler\<校准台账>`。

## Checklist
