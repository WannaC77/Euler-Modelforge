# 材料吸收层（W-ABSORB · 通用接入点）

> 触发：凡涉及「喂样例 / 吸收材料 / 对标升级」的任务，按本文件路由到吸收基建。**本产品不依赖任何特定 agent / CLI / 调度器**。
> 本文件只定义**机制**；吸收基建与锚集是用户自建资产，未自建时退化为清单式人工核验并标 `[降级]`。

## 一、吸收基建位置（唯一正本）

```
<共享层>/                        （可选，可自建）
  ├─ <吸收基准总表>.md    ABS-xxx 单一正本；所有产出定稿前必须回灌
  ├─ <负面迁移清单>.md    样例写了 ≠ 我方都写；吸收会话收尾必添条目
  ├─ <锚集注册规程>.md    盲评锚 / 已知答案锚 / 已知档位锚的注册与校准
  ├─ <吸收流水线>.md      批量吸收 7 步 SOP（每步有产物 + 核验）
  ├─ <锚注册卡>/          锚卡片目录（见 templates/锚注册卡模板.md）
  ├─ scripts/<吸收门>.py      回灌 gate（覆盖率 <100% 且未豁免 → exit 1）
  └─ scripts/<图像吸收>.py    图像 / PDF 三件套（ocr / vision / meta，强制）
```

> `<…>` 为**自建占位**：本仓库不随附这些文件，请按你的项目自建（命名可自定，机制照本文件）。

## 二、吸收 gate：三态与双向 set diff 纪律

- **三态（不得跳步）**：**候选报告 → 复核 → 写正本**。自动化 / 批量流程**唯一允许**的写盘动作 = 产出「候选报告」；是否写入正本由人工或独立会话**定期复核**后决定（复核内容：是否写入 / 表述是否需改 / 是否并入既有条目 / 归属落点 / 复发计数）。
- **写入执行**：同批备份（`.bak-<批名>`）+ 计数**脚本直出** + **双向 set diff**（改动件集合 ↔ 备份件集合，两侧差集均须为空）+ 回读校验。
- **覆盖率 gate**：产出目录回灌覆盖率 <100% 且未豁免 → 吸收门脚本（自建：`scripts/` 或你的工具目录） exit 1。
- **积压不得静默**：候选报告连续 3 个复核周期未处理 → 下次报告顶部标「⚠️ 积压 N 期」，不得静默。

## 三、吸收会话收尾固定输出（不得省）

```
本批次吸收完成：清点 N 份 / 吸收卡 x 张 / 图像三件套 y 张 / 总表新增 z 条（共 W 条）/ 负面迁移 a 条 / 锚注册 b 张 / gate 覆盖率 q%
```

缺任何一项视为收尾不完整；**总表行数与负面迁移条目数是硬核验**（脚本能跑即证，不靠自觉）。

## 四、与既有工作流的关系（不重复，不冲突）

- 模拟评审的「锚校准」读 锚集注册规程（自建） 取锚全集；`<校准台账>` 仍是**版本化与整改历史**的正本。
- 产出定稿前新增一步「absorb_gate 回灌」：通过后才进已有的自查 / 合规门禁。
- 图三种来源：① 自绘图（走你的绘图脚本）② 样例材料图（走 图片吸收脚本（自建） 三件套）③ 过程文档图（历史记录不动）。本文件只新增 ② 的强制管道，① ③ 不变。
