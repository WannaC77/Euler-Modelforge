## 第二步：模型选择

决策原则（重要）：
1. **先简单后复杂**：能线性规划解决的不用上神经网络
2. **匹配数据**：数据少的题别上深度学习（会过拟合）
3. **能解释优先**：评委要听你讲清楚模型，黑箱模型慎用
4. **1-2 个核心模型做深**，胜过 5-6 个模型堆砌
5. **模型-问题匹配自检**：每个模型必须答得出"对应题目哪条要求"。映射不到任何题目要求（如"显得高级"）的模型直接删除

⚠️ 冷水①：模型堆砌。O 奖/国一论文通常聚焦 1-2 个核心模型 + 必要子模块。

## 跨领域迁移（移植他学科模型，禁止生搬硬套）

从他学科移植成熟模型到本题，三步缺一不可：

1. **同构论证**：为什么本题结构与原场景同构？写出对应表（原域物理量 ↔ 本题量，原域规律 ↔ 本题机制）
2. **适配改造**：参数、边界、约束按本题条件重新定义；借用原域参数值须给取值依据（实测 / 文献 / 敏感性分析证明不敏感）
3. **本土验证**：移植后用**本题自己的**数据/特例验证；原域的验证结论不自动继承

⚠️ 生搬硬套的三种形态（命中即拒收）：只用名字不改造（提了模型名但假设/参数原样照搬）、直接抄原域参数取值、把原域结论当本题结论写。

## 模型融合（禁止简单平均）

题目确有需要才融合，合规做法：
- **加权融合**：权重由验证集性能或数据导出（如误差倒数、信息准则），禁止拍脑袋赋权
- **集成/Stacking**：基学习器用训练集训练，元学习器用验证集训练
- **分阶段组合**：各阶段输出各司其职（如问题一预测值 → 问题二优化输入），属结构性组合

**铁律（硬门禁 7）**：任何"融合"必须给出同验证集、同指标的**融合 vs 最优单模型**对照数据——有提升才保留（写明提升幅度），无提升如实写明并回退单模型。

## 第三步：模型建立

1. 定义变量、参数
2. 写目标函数 / 约束（优化类）或方程（方程类）或流程（仿真类）
3. 明确输入 → 输出
4. 模型可解性检查（有没有解、复杂度够不够）

### LS-5 判准条目必须定死「判定粒度」与「证验对象」（复发 2 次）

- **现象**：同一评分员按判准表两个视角都能「按表辩护」，同一份方案书出现 2.5 分差（A、B 两份）。具体：① 20–24 档③「**可执行**」未定义证验对象——A 题退化特例检验能立刻跑，但它只验证「代码符号没写错」、**不验证「建模选对了」**，甲按完备性计入给 22.0、乙按可执行性判定为设计态给 19.5；② 20–24 档②「**一一对应**」未定义粒度——B 题关键假设 A1 只有结构描述、未落具体方程，甲判「结构对应即满足」给 21.0、乙判「未到公式对应」给 18.5。
- **根因**：判准表条目用的是**抽象能力词**（可执行、对应、完备、自洽），但未规定**判定粒度**（到什么程度算满足）与**证验对象**（验证的是什么）。抽象词 + 无粒度 = 双方都能自圆其说。
- **执行要求**：
  1. **凡判准条目出现抽象能力词，必须同时写清两件事**：① 判定粒度（最低满足形态）② 证验对象（这条验证的是「逻辑对不对」还是「能跑起来」还是「选型对不对」）；
  2. 已定的两条细化（**P1-P1 进行中禁止改表**，待修订窗口开启后按任务书 §1.5 程序执行）：
     - **E1/E2/E3 分级**（消解 A 题分差）：E1 = 有方程可代入（含状态变量/参数/量纲）；E2 = 有方程 + 参数 + 数据需求（参数取值依据 + 数据字段→特征映射）；E3 = E2 + **可立即运行的最小闭环**（不依赖缺失附件，合成数据/特例可跑）。**给分对应：20–24 档③须至少一处 E3**，E1/E2 可计入但不足以单独满足③。
     - **对应粒度**（消解 B 题分差）：「模型↔假设一一对应」的最低粒度 = **关键假设必须落到具体方程或具体算法步骤**；仅结构描述（只有模型名 + 项名）**不得计入「一一对应」**，只能算「结构对应」，按 18–19 档「假设基本完整」论。
  3. **反通胀条款判定边界**：模型名词清单须逐项标注**采用／排除／降级**及理由；**反通胀条款只对「采用」项计数**，「被排除项」（如 B 题 §2.4(c) 的 NSGA-II）**不计入**名词堆砌。此条同时给高名词密度样本一个**可机械判定**的口径。
  4. **区分度监测**：判准表需保证同题分差 ≥ 阈值（读数不足 1.5 分即为「尺子区分度不足」，须重校而非放宽）。评分数跨度过窄（如 1.25）本身就是欠账信号。

### 回写 3.1 —「可执行」的 E1/E2/E3 分级（补 20–24 档③「可执行」的证验对象）

**问题**：③只写"至少一处**可执行**互验/基线/特例"，未规定**验证什么**。可立即跑起来的退化特例检查（A 题 §5.1）只证明"实现没写错符号"，**不证明"建模选对了"**——两位评分员据此合理落到 22.0 / 19.5 两侧。

**分级定义（三级，按"可交付物颗粒度"逐级加厚，非按"跑不跑得动"）**：

| 级 | 定义 | 判据 |
|---|------|------|
| **E1** | **有方程可代入** | 关键机制可写成分式/方程，含状态变量、参数、量纲 |
| **E2** | **E1 + 参数 + 数据需求** | 每个参数有取值依据（实测/文献/量级论证）；写明"哪个数据字段→哪个特征/参数"的映射与数据缺位影响 |
| **E3** | **E2 + 可立即运行的最小闭环** | 不依赖任何缺失附件即可跑起来的最小闭环（合成数据 / 特例退化 / 解析对照），**并写清数据来源、指标与通过阈值** |

**M-plan 给分对应级（定死）**：

- **20–24 档③要求至少一处 E3**；E1/E2 可计入"检验设计"，但**不足以单独满足③**（单独满足只到 18–19 档「互验/检验偏薄」）。
- **E3 不等于"已执行"**：E3 仍是设计态（本规则不要求跑通代码，§1.3.2 沿旧）；"已执行"为**加分观察**，不进 M-plan 达标。
- **不得把 E3 写成"结果正确性"证据**——只证明"变换/方程/输出链在数学上自洽、输出恒合法"。

**生成侧动作（下一轮生成器）**：§5 互验章每条标注所属级别（`[E1]`/`[E2]`/`[E3]`）+「设计态/已执行」；**至少一条标 `[E3]`** 并写清数据 / 指标 / 通过阈值 / 不过怎么办四要素。

### 回写 3.2 —「一一对应」的最低粒度（补 20–24 档②「一一对应」）

**问题**：②只写"假设与模型**一一对应**、含现实依据"，未规定细到**什么粒度**。B 题 A1 只有结构描述（"Logistic + 拉普拉斯扩散 + 迁移 + 死亡"）而无完整方程，两位评分员据此合理落到 21.0 / 18.5 两侧。

**最低粒度（定死）**：关键假设必须落到**具体方程**或**具体算法步骤**，二者至少落其一。

- ✅ 计入"一一对应"：假设 → 可写下的方程（含状态变量 / 参数 / 量纲）**或** → 可指认的算法步骤（输入→处理→输出，含判据）；
- ❌ **不计入**：仅**结构描述**（只有模型名 + 项名，如"含扩散项""带 Allee 效应"）；仅**并列候选未裁决**（如"Leslie 型／含 Allee 效应的捕食—被捕食修正方程"三选一并列表述）；
- 结构描述只能算「**结构对应**」，按 18–19 档「**假设基本完整**」论。

**对全案的要求**：① 每个"核心模型"的**枢纽机制**（决定结论走向的那一项）必须有显式方程，不得停留在项名；② 假设清单中，**自述为"最强/枢纽"的那条**若对应环节是结构描述 → 直接触发本条的降档。理由是自证：作者自己认定它是枢纽，就不允许以"细节待定"豁免。

**生成侧动作（下一轮生成器）**：§3 假设表增列「**对应环节（方程/算法步骤）**」，逐条写明落在哪个编号的方程或哪个步骤；枢纽机制在 §4 必须给出**显式方程**（不得以"函数族""单调增函数""弹性可调"等形式回避）。

### 回写 3.3 — 模型名词清单强制披露（补反通胀条款的可机械核查口径）

**问题**：反通胀条款只写"多模型名词并列无对照 → 封顶 17"，**未定义什么算"并列"**。B 题模型名词密度为 N=6 最高（Leslie 型、Allee 效应、捕食—被捕食、扩散—迁移、多目标规划、熵权、TOPSIS、NSGA-II、蒙特卡洛、质量作用定律）却被裁决**不触发**——因 §2.4(c) 把 NSGA-II 写成**被排除**项而非并列项、且 §5.5 有结构变体对照。若无此裁决，B 题会被误帽封顶。

**判定边界（定死）**：**反通胀条款只对"采用"项计数**。

| 状态 | 含义 | 是否计入名词堆砌 |
|---|---|---|
| **采用** | 进入核心模型或结论路径 | ✅ 计入；并列无对照即触发封顶 |
| **排除** | 候选但明确**不采用**（写明裁决依据与降级门） | ❌ **不计入** |
| **降级** | 采用但从属/仅作基线，**不合入主干** | ❌ 不计入堆砌；但须写明"不合入主干" |
| **未裁决** | 候选并列表述、未给裁决 | ⚠️ **计入**（并列悬置本身即堆砌形态） |

**生成侧动作（下一轮生成器）**：方案书自检增一节「**模型名词清单**」，逐条列出全部模型名词 → 标注 `采用／排除／降级` 状态 → 给理由与依据。要求：

1. 清单**穷尽**（正文出现的每个模型名词都要在清单里出现一次）；
2. "排除"项必须写明**裁决依据 + 若…再降级的决策门**（如 B 题 §2.4(c) 的"格点 >10⁴ 或需完整 Pareto 前沿才降级用 NSGA-II"）；
3. "采用"项若 ≥2 个并列，必须给出**同验证集同指标的结构对照**（硬门禁 7 口径），无对照即触发封顶 17；
4. 声明**是否做模型融合**（如未做融合，明写"结构性串联非融合，不适用硬门禁 7"）。
