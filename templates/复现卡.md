# 复现卡（E-M4 · 求解复现）

> **用途 / Purpose**：让任何人（含三天后的自己）用「环境 + 数据版本 + 一条命令」复现出同一批数字与图表；复现不齐的结果不进论文。
> **对应工作流 / Workflow**：`workflows/05-编程求解.md`（§代码规范 / §结果验证 / §算法改进合规）；报告节口径见 `references/求解报告规范.md`
> **门禁指针 / Gates**：`Euler-ENGINE.md` §1 **E-M4**（求解工坊）——**模板冒烟 rc=0**；**种子固定**；**报告卡齐**；改进四件事（基线/改动/量化/公平对照）；§3「求解」行
> **降级 / Fallback**：手写脚本 + 人检；缺 venv → 系统 Python 并声明（标 `[降级]`）
> **填写时机**：每次产出「进论文的结果」时同步填一张；改代码 → 升版本重填

## 3 · 命令

```bash
# 一行可复跑（工作目录 <…>；解释器用 venv）
<<venv>/Scripts/python solve_q1.py --config configs/q1.yaml --seed <N> --out artifacts/RC-<N>/>

# 图表产出（如需）
<<venv>/Scripts/python make_figs_q1.py --in artifacts/RC-<N>/ --out assets/>

# 模板冒烟（首次用模板必跑；确认 rc=0）
<<venv>/Scripts/python smoke_all.py>      # 或缺该脚本时，跑模板自带 `python -m` 自检
```

- 命令必须**可直接粘贴执行**；含相对路径、参数与输出目录。
- 冒烟口径：`python smoke_all.py` 退出码 **0**；本次记录：rc=<0/非0 + 处理>。

## 6 · 差异容忍

| 项 | 容忍限 | 超限动作 |
|---|---|---|
| 重跑同一命令的数值差 | <≤ 1e-6 相对误差（定种子，应完全一致）> | <查种子/浮点/并行非确定性；查清前不写进论文> |
| 换机器/换环境的数值差 | <≤ <0.5>%（列出差异来源：库版本/数值库）> | <锁依赖版本；在论文附录声明环境> |
| 与文献/基线的差 | <≤ <…>%；超出即须解释原因> | <补实验或降级措辞（不得美化）> |
| 随机算法多次运行 | <均值 ± 标准差；报告均值±sd，不只报最好一次> | <增加重复次数；报告分布> |

## 9 · 填写说明

1. 一张卡对应**一次进论文的求解**；同一次运行产出多个子问题结果时可共用卡，但产物列要齐。
2. 「预期输出数值」是复现的**验收线**：后来者跑出的数字落在容忍内才算复现成功。
3. 任何一处改动（数据版本/参数/种子/依赖）→ 新开版本（v2），旧卡不覆盖。
4. 卡与 `references/求解报告规范.md` 的报告节配套：卡是证据，报告是叙述。
5. 论文附录的可运行文件清单直接由多张卡的产物列汇总生成。
