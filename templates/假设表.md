# 假设表（E-M2 · 三段式：表述 + 依据 + 对应环节）

> **用途 / Purpose**：把建模假设写成可核验的三段式条目（具体断言 + 依据 + 违背后果），并逐条挂钩到方程/算法步骤；每条假设评委都会问「凭什么」。
> **对应工作流 / Workflow**：`workflows/03-问题分析与假设.md`（§假设清单 / §假设书写合规）；对应环节粒度见 `workflows/04-建模.md` §生成锚回写区 3.2
> **门禁指针 / Gates**：`Euler-ENGINE.md` §1 **E-M2**（假设表）——三段式（表述+依据+对应环节）；**空话假设黑名单零命中**；符号与代码/论文一致；§3「建模」行
> **降级 / Fallback**：手工两表 + 一致性人检（并标 `[降级]`）
> **填写时机**：拆题后、写首版模型前（`_SHARED.md` §3：Day1 问题拆解与假设）；模型迭代时同步增补，不事后补写

### 1.1 三段式填写口径

| 段 | 对应列 | 要求 |
|---|---|---|
| ① 具体断言 | 假设表述 | 可判真假、含量级或范围；禁「为简化模型，假设…」 |
| ② 依据 | 依据 | 三态标注：`[事实]` 有出处可核 / `[推断]` 由事实推得 / `[假设]` 未验证的猜测（须附论证）；参数取值依据见 `Euler-CORE.md` 细节精度 |
| ③ 违背后果 | 风险 | 写清「如果不成立会怎样」+ 兜底手段（`workflows/03`） |

### 1.2 空话假设黑名单（命中即拒收）

（正本：`workflows/03-问题分析与假设.md` §假设书写合规）

- 「忽略所有影响因素 / 所有随机扰动」——必须列出具体忽略了哪些因素
- 「假设数据完全准确无误差」——与现实矛盾，且与后文误差分析自相矛盾
- 「假设所有参数取理想值」——参数取值必须有依据
- 「为简化模型，假设……」——不说简化了什么、凭什么能简化

**合规示例（口径示范，替换为本题内容后使用）**：

```text
❌ 「忽略空气阻力。」
✅ 「忽略空气阻力（[事实] <某实测/文献量级证据，如：效应比重力回复力小一个量级>）；
    若不成立，需引入阻尼项并补充阻尼系数敏感性分析。」
```

**修正三步**（对每个被忽略因素）：忽略了什么 → 凭什么能忽略（量级对比 / 数据支持的相关性弱）→ 忽略后如何兜底（模型检验 / 敏感性分析覆盖该参数）。

## 2 · 对应环节（粒度下限·硬要求）

（正本：`workflows/04` §回写 3.2；判准：**关键假设必须落到具体方程或具体算法步骤**，二者至少落其一）

| 粒度 | 是否计入「一一对应」 | 形态要求 |
|---|---|---|
| 具体**方程** | ✅ 计入 | 含状态变量 / 参数 / 量纲，可指出「式(N)」 |
| 具体**算法步骤** | ✅ 计入 | 输入→处理→输出，含判据（可指认「步骤 N」） |
| 仅**结构描述** | ❌ 不计入（只能算「结构对应」，按 18–19 档论） | 只有模型名 + 项名（如「含扩散项」「带 Allee 效应」） |
| **并列候选未裁决** | ❌ 不计入 | 如「A 型 / B 型 / C 型三选一并列」 |

**硬约束**：① 每个核心模型的**枢纽机制**（决定结论走向的那一项）必须有**显式方程**，不得停留在项名；② 自述为「最强 / 枢纽」的假设若对应环节是结构描述 → **直接触发降档**（作者自己认定它是枢纽，就不允许以「细节待定」豁免）。

### 2.1 假设 → 模型 → 方程/步骤 映射（与模型卡联动）

| 假设编号 | 落入的模型（`templates/模型卡.md` 卡号） | 方程编号 / 算法步骤 | 反向核对（该方程还依赖哪条假设） |
|---|---|---|---|
| A1 | 卡 1 · <模型名> | 式(3) / 步骤 2 | <…> |
| A2 | <…> | <…> | <…> |

> 反向核对必做：每个核心方程都要能指认它依赖的假设；孤立假设（没有任何模型用到）= 应删。

## 3 · 验证方式 · 允许值

（取 `workflows/06-模型检验与敏感性分析.md` §模型检验表的检验方式）

`特例验证` · `对比验证（与已有方法/文献/朴素基线）` · `拟合检验（R²/调整 R²）` · `残差分析（QQ/方差齐性/自相关）` · `交叉验证（K 折，K=5）` · `鲁棒性测试（加噪/删样本/放松假设）` · `收敛性检查（重复次数/代数 vs 指标稳定性）`

- 每条假设至少 1 种验证方式；无法直接验证的（如理想化条件）写「由 <某检验> 间接覆盖」或列入模型评价的局限。
- 全表验证方式**并集**须满足 E-M5 门禁：模型检验 ≥2 种且与题型匹配（`workflows/06` §选型指引）。

## 4 · 填写说明

1. 假设按**出现顺序编号**（A1、A2…），全文/代码/论文引用同一编号；中途插入用 A1a，不重排。
2. 「依据」列写不了出处的，说明它其实是「想当然」——回去找量级论证或数据支持；找不到就降级为局限，不要硬写成假设。
3. 假设数量控制 5–10 条：粒度过细的（如「单位用 SI」）合并为一条前置说明，别占假设名额。
4. 与数据矛盾即废：任何假设不得与附件数据冲突（冷水④：假设随意 = 没论证、与现实矛盾）。
5. 赛中新增/修改假设 → 同步更新本表 + 受影响的模型卡 + 符号表，**三处同改**（`templates/符号表.tex` 一致性检查卡）。
6. 论文「模型假设」节直接由本表产出：正文写表述与依据，风险与兜底进「模型检验」或「模型评价」。
