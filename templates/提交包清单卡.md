**MD5 注意事项**（`workflows/08` §MD5）：

- ⚠️ 生成 MD5 后，只要**再次打开保存**（含自动保存/预览导出），MD5 可能变化 → 有改动就**重新生成并上传最新值**。
- 生成顺序：确认最终版 → 关闭编辑器 → 生成 MD5 → 登记本表 → 上传 → 上传后核对服务器端文件名与大小。
- 文件命令（任选其一本机可用者）：

```bash
# Windows（git-bash）
md5sum "<文件名>"            # 或 certutil -hashfile "<文件名>" MD5
```

## 9 · 填写说明

1. 本卡在**冻结时刻**开始填，逐项写「实测值」，只打钩不写实测值的行视为未核。
2. 任一项 FAIL → 回到对应工作流修复（预检 FAIL 按输出逐项处理），修复后**重跑该项**并更新本卡。
3. 交付物之间的数字一致性（论文 ↔ 支撑材料 ↔ AI 详情）抽 ≥3 处比对，写入 §1-5 / §2-4。
4. MD5 表生成后不得再打开保存源文件；确需改动 → 回到 §1 重走。
5. 交卷后本卡与提交回执一起归档，供复盘（`learnings.md` 与 `09-知识管理` 复盘节）。
