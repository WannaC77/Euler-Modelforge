# 拆题卡（E-M1 · 题目 → 子问题拆解）

> **用途 / Purpose**：把赛题文本拆成可建模的子问题，逐题给出题型初判、模型族初判与数据可得性判定——本卡是假设表（E-M2）与模型卡（E-M3）的输入。
> **对应工作流 / Workflow**：`workflows/02-选题与读题.md`（读题/选题）· `workflows/03-问题分析与假设.md`（拆解/问题分析）；方法层正本 `references/获奖级方法论/problem-decomposition.md`
> **门禁指针 / Gates**：`Euler-ENGINE.md` §1 **E-M1**（拆题卡）——字段完整；子问题有题型/模型族初判；数据可得性；§3「拆题」行
> **降级 / Fallback**：方法论件缺失时手工拆题 + `Euler-CORE.md` 铁律（并在卡内标 `[降级]`）
> **填写时机**：前 6h 内（`workflows/_SHARED.md` §3 时间表）；定题后全员冻结、不回头（`workflows/02` §选题决策）

### 3.1 题型初判 · 允许值

- **建模类（`workflows/04` §第一步 8 大类）**：优化 / 预测 / 评价 / 统计（数据）/ 微分方程 / 图论（网络）/ 仿真 / 智能算法。
- **本质级细分（12 类）**：见 `problem-decomposition.md` §第 2 步十二大问题类型；混合类型按「前置类型 → 后置类型」顺序标注（如「预测 + 优化」）。
- **非建模问题**：纯确定性计算 / 题给公式代入 / min 截断等，**显式标注「确定性计算」**并写出计算公式，不查模型矩阵。
  - 判别问句（`problem-decomposition.md` §第 0 步）：两队解这道题会不会合理选择不同的方法？答「不会」→ 确定性计算。
- 题面**明确要求**「建立…模型」的，无论看起来多像计算，一律按建模问题处理。

### 3.2 模型族初判 · 允许值

按 `references/获奖级方法论/model-selection-matrix.md` 的 **12 个家族**取一名（或「家族 A + 家族 B」并注明主次）：

预测/回归 · 分类/判别 · 评价/排序 · 优化/决策 · 机理/物理 · 聚类/分组 · 关联/因果 · 博弈/策略 · 几何/运动学 · 统计推断/实验设计 · 网络科学/图论 · 生态系统/环境

> 此处只写**家族级初判**（粗选方向）；具体模型名落 `templates/模型卡.md`（E-M3），冲突裁决规则见矩阵 §冲突裁决规则（题目特征 > 规模 > 本队背景）。

### 3.3 数据可得性 · 允许值

| 取值 | 判据 | 必填补充 |
|---|---|---|
| 附件直接可得 | 附件给全且字段清晰 | 附件号 + 字段清单 + 单位 |
| 需外部检索 | 公开数据集 / 年鉴 / 文献数据 | 来源 + 版本 + 日期 + 获取方式（`workflows/05` §数据来源与处理交代） |
| 需自采 / 需仿真生成 | 题面无数据但可合成 | 生成规则 + 与真实数据的差异声明 |
| 缺位（不可得） | 关键字段拿不到 | 替代方案或改为「确定性计算」/ 换题信号 |

⚠️ 数据可得且清晰的题优先（`workflows/02` §选题决策第 3 条：「没有数据一切白搭」）。任一子问题标「缺位」→ 回 `templates/选题评估矩阵.md` 重议选题。

## 7 · 填写说明

1. **先判是否建模**（`problem-decomposition.md` §第 0 步），再判本质类型，最后才填模型族——顺序颠倒会选偏模型。
2. 子问题表的「要求」列写**题面原话摘要**（可核对）；「题型初判」列写允许值；两列不得混写。
3. 「难点」列写**本题的**具体困难（数据缺失/耦合强/规模大/参数未知），并注明拟用什么手段应对；空话式难点（「有一定难度」）不合格。
4. 本卡只做**方向性判断**，不写具体方程与参数（那是 `templates/假设表.md`、`templates/模型卡.md` 的活）。
5. 每行判定都要能回答「依据是什么」；依据在题面/附件的写出处，推断写 `[推断]`，猜测写 `[假设]`（`_SHARED.md` §6 三态标注）。
6. 定题后本卡冻结；赛中若发现子问题判定错误，**新增附页**说明改动与理由，不覆盖原判（保决策可追溯）。
