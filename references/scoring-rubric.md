# 评分判准（<校准标准>）— 分维判准 / 结构帽 / 贴档双评 / 低档帽

> **用途**：模拟评奖 / 盲评判档的**可复算判准**——把「凭感觉打分」压成「按清单累计到分带 + 结构帽封顶 + 贴档双评」。
> **框架件**：§5 锚表为**空表**，须用自己的已知档位样本填满后方可使用（§5.1）。
> **适用 / 联用**：数学建模类竞赛模拟评奖、盲评、自审（O/F/M/H 与 国一/国二/省一/省二 双口径）；配套 `workflows/_SHARED.md` §2 权重表（默认 25/25/15/15/10/10）。
> **中性声明**：本产品不依赖任何特定 agent / CLI / 调度器；判准可由人或任意会话执行。
> **总纪律**：判准是**尺子**不是**目标**：改尺子的动机必须是「更准」，不是「让我方材料好看」（动机审计见 `workflows/_SHARED.md` §2）。

## 1. M 维操作判准（深度维 · 防漂移主刀）

> 禁止「感觉很深就给高分」；按清单累计到分带，**边界情况向下取整到整数**。

| 分带 | 必须同时满足 |
|---|---|
| 22–24 | ①问题→机制→模型因果链可复述 ②本题独有内核（结构/定理/闭式/算法，非教材平移）③≥1 处基线对照或双方法互验 ④假设与模型一一对应可追问 |
| 20–21 | ①选型有必要性论证 ②深度完整非堆砌 ③有互验/特例/闭式之一 ④缺独创内核或对照弱 |
| 18–19 | ①标准工具链正确组装 ②覆盖全部子问 ③互验偏薄或证明口语 ④无明显堆砌 |
| 16–17 | ①工具正确 ②1–2 处流程完整 ③深度一般、创新有限 ④组合感强于突破感 |
| 14–15 | ①方法正确但浅 ②仿真/启发式替代精解 ③缺检验或点到为止 |
| ≤13 | ①堆砌明显 ②与题目脱节 ③关键机制未建模 |

**反通胀**：「多模型名词并列但无对照」→ M 封顶 **17**；「改进/融合」无基线 → M 封顶 **16**；**只对「采用」项计数**（方案书须列全部模型名词并逐项标**采用／排除／降级**及理由）；`17/16` 为经验值，须重校。

## 2. 结构帽（只封顶不加分）

先勾二进制特征，再封顶对应维，记入评分表 `caps` 栏：

| 特征 | 触发 | 帽 |
|---|---|---|
| C1 摘要无任何可点名数字结果 | 是 | A ≤ 18 |
| C2 无互验/特例/闭式/交叉验证 | 是 | T ≤ 10 |
| C3 无代码/无参数表/无复现说明 | 是 | S ≤ 8 |
| C4 仅关键词堆模型、无「为何必须此模型」 | 是 | M ≤ 17 |

**低档帽**：双评后 `M_final ≤ 15` → 判档**不得高于最低档**（总分落次低档带则强制降档）。
> ⚠️ `18/10/8/17/15` 全为**经验值，必须用自己的锚重校**：统计各档 M 分布——低档帽取「低一档样本 M 上界」，维帽取「该档典型上界」。

## 3. 贴档双评协议

### 3.1 贴档区（Z 区）

| 区 | 总分 | 含义 |
|---|---|---|
| **Z1** | 60–65 | 次低档/最低档粘连 |
| **Z2** | 68–72 | 第二档/次低档粘连 |
| **Z3** | 74–75 | 最高档擦边 |
| **ZG 门槛未过件** | ≥76 且 M≤19；或 70–75 且 M≤17 | 浅模型高总分 / 第二档门槛未过 |

> 76 且 M≥20 的真高档不进 Z3；Z 区为经验边界，填锚后重校。

### 3.2 双评流程

1. **评 A**：常规六维（可带初印象）。
2. **评 B**：**只看本文件（M 判准 + 结构帽）**，禁止先看评 A。
3. 总分取两评中位数；**跨档 → 第三评 C**（换题型视角）或「档位不确定，建议人工终裁」。
4. 双评两套维分都记入决策日志。
> A/B 必须**隔离上下文**（独立会话 / 子 agent）且 B 评读取面留痕，否则「隔离」不可证。总分 ≤59 或 ≥73 且不在 Z/ZG 边：单评 + 结构帽。

## 4. 判档合成

```
1. 六维打分 → 过结构帽 → capped 分；total = A'+M'+T'+F'+S'+H'
2. 落 Z1/Z2/Z3/ZG → 双评（§3）；双评优先于单评带
3. 常规带（单评+帽）：最高档 total ≥76 且 M' ≥20 ｜ 第二档 70–75 且 M' ≥18
   次低档 60–69 ｜ 最低档 ≤59
4. 跨档不可收敛 → 标注「边界样本」
```

> 判档线全为**经验值，必须用自己的锚重校**（§5.1）。逐件给**贴线余量**=|总分−最近判档线|；余量 ≤1 分 → 标「**贴线敏感**」；**档位≠分数单调函数**（不要用「某篇高档只有下限分」反推阈值该降）；样本扩充前禁止称判档线为「稳定常数」。

## 5. M 维校准锚（**空表 · 必须自己填**）

> 本表是判准的「标尺刻度」：没有锚，判准就是空转——必须用**已知档位**材料当参照物。

### 5.1 填锚规程

1. **收样本**：≥5 篇**已知档位**材料全文（各档尽量覆盖；来源自选，注意版权，正文不入仓库）。
2. **注册**：每篇一张锚注册卡（题号/年份/档位/来源/**档位如何确认**），只提交卡（`templates/锚注册卡模板.md`），不提交正文。
3. **打标入表**：用 §1 打 M 分 + 记「一眼特征」→ 填 §5.2。
4. **校准**：统计各档 M 分布 → 回校 §2 帽值（取低一档样本 M 上界）与 §4 判档线（取已知达档样本最低分）。
5. **隔离**：**规则制定样本与验证样本必须分离**（A 批定规则 → B 批验规则，见 §6）；每次重校记入 `<校准台账>`（`templates/校准台账模板.md`）并在 §7.2 升版本号。

## 6. 已否证路径（禁止重走）+ 验证与回滚

> 下列做法已被否证，列出以免重走；具体数值属校准者私有数据，只留**结论形态**。

| 路径 | 结论 | 理由形态 |
|---|---|---|
| **双门限地板**（总分外加维地板修命中） | **禁止** | 地板版命中率**低于**纯总分版：误伤「维分低但总分够」的真样本，修不回跨级件 |
| **模糊标记当档位标签**（如「优秀」「汇编优秀」） | **禁止计入正式命中** | 映射产生假失败；验证集只收明示档位样本 |
| 权重/帽重构**由同批数据提出** | **不采纳**（除独立验证集有增益） | 自证循环：用被评样本自身数据改规则必然「通过」 |
| **判档线当稳定常数** | **禁止** | 以最低样本分踩线的余量为 0，样本扩充前不是常数 |

### 6.1 验证与回滚（必须预设）

```
验证：每批独立验证集 ≥10 篇明确档位样本，命中率 ≥ 达标线 → 该版判准 PASS
回滚：任一批低于回退线 → 回退上一版判准（保留本文件，改回滚指针）
停用：连续 2 篇跨级判错，或单批跨级 ≥2 篇（含观察件复现）→ 评审端停用复校
```

> 达标线/回退线与 `10 / 2` 均为**经验值，必须用独立样本重校**（起点：达标线取「显著高于随机猜档」的占比），写入 `<校准台账>`。**「验证通过」只能由独立样本产生**；**自评与盲评分差 >5 分（百分制，经验值）时不得作交付质量依据**。

## 8. 时间盒

| 场景 | 流程 |
|---|---|
| **赛中**（72–96h 冲刺） | 贴档区快评 5 min/件；锚校准**跳过**；缺陷谱系扫描 ≤10 min |
| **备赛 / 复盘** | 完整双评 + 锚校准 + 全量观察件复核 |

> 时间盒是**铁律**：不裁剪的完整评审流程在赛中跑不完；赛中用快评、备赛用全流程（时间参数为经验值，按自己节奏重校）。
