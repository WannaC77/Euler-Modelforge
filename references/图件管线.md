## 0. 铁律（先读）

1. **画布物理尺寸 = 论文实际插入宽度**：`figsize=(插入宽cm/2.54, 高/2.54)`。9 英寸画布缩到 15.5cm 后字号乘 0.68——这是「屏幕看着大、纸上读不清」的唯一根因。国赛正文图插入宽一般 15.5–16 cm；栏宽图 13 cm。
2. **交付前必过三闸**：`audit_fig`（字号+裁剪）→ `figcheck`（文件层）→ **主模型 vision 复核**（逐字/越界/重叠）。三闸全过才可进论文；缺一不可。
3. **图服务于论证**：做图前先写 Figure Contract（见 §1）；一个 panel 不贡献独立证据就删除，不要为填满画布加图。

## 1. Figure Contract（做图前四步）

1. **核心结论一句话**（带数字）：「λ 从 0.01 增至 0.1 时 F1 提升 5.7%，继续增至 1.0 反而下降 6.2%——过强正则化损害拟合」。
2. **证据链**：逐 panel 写「它贡献什么独特证据」；无贡献 → 删。
3. **图原型分类**：定量网格（同类型多图，共享轴）/ 示意主导（核心示意图占 40–60%）/ 数据+图例混合 / 非对称混合（GridSpec）。
4. **审稿风险检查**：黑白打印能否读出结论？只看图不读正文结论是否成立？有无红绿同现（色觉缺陷）？

> 模板（贴在做图脚本头部注释）：
> ```
> # [Figure Contract] 结论：<一句话带数字>
> # panel a: <独特证据> | panel b: <独特证据>
> # 原型：定量网格/示意主导/…  审稿风险：黑白✓/只看图✓/色盲✓
> ```

## 2. 双风格与基本用法

```python
from utils.plot_style import style_plot, save_pub, audit_fig, add_units, next_style

style_plot("cumcm")        # 国赛：微软雅黑系中文、左/下轴、浅网格、学术蓝系
fig, ax = plt.subplots(figsize=(6.1, 2.7))   # ← 6.1in = 15.5cm 插入宽
c, ls, mk = next_style(0)  # 颜色+线型+标记（灰度安全组合）
...
add_units(ax, xlabel="时段", ylabel="产出量", xtitle="时间 (h)", ytitle="累计产出")
audit_fig(fig, insert_cm=15.5)               # 闸 1
save_pub(fig, "assets/图1-两方案对比")        # PNG+PDF+SVG 三格式
```

- 美赛：`style_plot("mcm")` → Times/Arial 衬线 + 四边框盒式 + 内向刻度（Origin 风）。
- 旧代码兼容：`style_plot(font_size=11, dpi=300)`、`apply_style`、`save_fig` 均保留。
- **三格式**：PNG（Word/预览）· PDF（LaTeX 插入）· SVG（Word/PPT 可编辑、文字不转曲）。

## 3. 调色板三原则

1. **统一方法族 > 最大色相分离**：同图多系列优先同色系深浅，而非跳跃色相。
2. **灰度打印安全**：`next_style(i)` 轮换「颜色×线型×标记」，去色后仍可区分。
3. **红绿仅作方向信号**（增益/损失）；中性数据用蓝/灰/橙。多面板密集图用 `PALETTE["nmi"]` 低饱和。

## 4. 交付三闸（细节）

| 闸 | 工具 | 查什么 | 通过线 |
|---|---|---|---|
| 1 字号/裁剪 | `audit_fig(fig, insert_cm=…)` | 纸面有效字号（按插入宽折算）、疑裁剪文本 | 全部 ≥7.5pt（标题建议 ≥10pt）；`raise_on_violation=True` 可作脚本硬门 |
| 2 文件层 | `python utils/figcheck.py 图.png` | 真图片格式、宽/DPI、白底内容占比 | 宽 ≥800px 或 DPI ≥150；内容占比 ≥0.5%；exit 0 |
| 3 视觉复核 | 主模型 vision（vision_analyze 传图+逐字转写问题） | 逐字转写全对、无 tofu/越界/重叠 | 转写与预期逐字一致 |

> 备注：`audit_fig` 的「疑被裁剪」为**提示级**（tight 裁边前的画布边缘检测），人工看一眼即可；字号违规为硬性。
> 中文流程图（技术路线图等）另用 `cn-scientific-figure` 技能的像素级越界检测模板（比字号门禁更严）。

## 5. 流程图（数模口径摘要）

- 70% 获奖论文有「整体建模框架图」（问题分析章末）；B 题/复杂 A 题另配算法流程图（求解章）。
- 框型语义：圆角矩形=输入/输出；矩形=处理/模型；菱形=判断；圆柱=数据。箭头标数据流或「是/否」。
- 配色 2–4 层（输入→处理→输出），学术蓝/灰/橙，禁大红大绿；子问题用同色系深浅。
- **六种风格择一**（详见 `references/` 收录摘译）：①横向箭头链（最简）②纵向分层递进（国赛最常见：数据预处理→建模求解→模型检验三带）③数据→方法→结果三栏平行 ④中心辐射 ⑤泳道 ⑥矩阵式。
- 工具：matplotlib（本机模板见 cn-scientific-figure）· PowerPoint COM（形状+导出，适合机理/装置示意）· LaTeX/TikZ（xelatex 在本机可直接编译）。
- 导出矢量优先（PDF/SVG）；禁止截图、代码运行截图。

## 6. 失败模式速查（改前先查表）

| 现象 | 根因 | 修正 |
|---|---|---|
| 纸上字太小 | 画布未按插入宽设计 | 画布=插入宽；再 audit_fig |
| 虚线间露底色的第三种颜色 | 共享边重复叠画 | 单层/并行（对称偏移）/分段 三策略 |
| 标签有白块、压线 | 不透明 bbox | 手动偏移；白描边仅作最后手段 |
| 节点像贴纸盖住线 | 默认白填充 | 透明填充；箭头 shrinkA/B 停边界 |
| 图放进论文跑版 | tight 裁边吃掉留白 | 提高 DPI 保物理尺寸；重查标题被裁？ |
| 重点系列不突出 | 层级/线型不一致 | 主系列最后绘制 + 直接标注 |

## 6.5 PPT 制图 SOP（2026-09-19 真机试点通过）

适用：机理示意图/装置图/流程图中「形状自由度高于数据图」的场合。链路：**python-pptx 画形状 → PowerPoint COM 导出高清 PNG**（矢量可另存 PDF）。
试点工件：`ppt-pilot.*`（2400×1322 @508dpi，figcheck PASS；视觉复核：无缺字/溢出/箭头错位）。

要点（试点实测）：
1. **slide 物理尺寸 = 插入尺寸**：`prs.slide_width = Inches(插入cm/2.54)`——字号即纸面字号（与 matplotlib 同法则）。
2. **去阴影必做**：python-pptx 形状默认继承 PPT 主题阴影，导出图带投影（论文图不允许）——`sp.shadow.inherit = False`。
3. **导出（win32com）**：
   ```python
   app = win32com.client.Dispatch("PowerPoint.Application")
   pres = app.Presentations.Open(abs_pptx, ReadOnly=True, Untitled=False, WithWindow=False)
   pres.Slides(1).Export(png_path, "PNG", W_px, H_px)   # W_px = 插入in × dpi（4.72in×508 ≈ 2400px）
   # 矢量另存：pres.SaveAs(pdf_path, 32)  # 32 = ppSaveAsPDF
   pres.Close(); app.Quit()
   ```
4. **样式纪律**：浅底色 + 同色 1.2pt 描边 + 同色粗体字（语义配色同 §3）；箭头统一 `#1F4E79`；中文微软雅黑、图注 8pt；三框等宽、箭头居中锁定。
5. **交付**：形状图不适用 audit_fig（无 mpl 文本对象）——以「slide=插入尺寸」保证字号，再过 figcheck + 主模型 vision 两闸。
