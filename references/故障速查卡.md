## 1 · LaTeX / 编译线

| # | 现象 | 根因 | 处置 | 复验 |
|---|---|---|---|---|
| 1.1 | MiKTeX：`FATAL - No suitable temporary directory found`（编译中途失败，无 PDF） | 子进程 `TEMP/TMP/TMPDIR` 指向不可用目录——MSYS/CI 下 `TEMP=/tmp`，或指向已被删除的临时目录 | 显式把 `TEMP/TMP/TMPDIR` 设为**存在的原生 Windows 临时目录**再调 xelatex（`tools/smoke_chain.py` v1.1 已归一，自动自建 `_smoke_out/_tmp`） | 复跑 rc=0 且出 PDF |
| 1.2 | MiKTeX：`major issue: So far, you have not checked for MiKTeX updates`＋编译失败（历史日志另见 `not registered` 仓库 FATAL） | 用户级 MiKTeX 仓库未注册/未更新检查，缺包在线安装失败 | **优先 TeX Live 2026**（`paper-templates/编译自检.bat` 正序：`<TeX 安装目录>/` → MiKTeX 兜底；smoke_chain v1.1 同序）；要修 MiKTeX 则 `miktex packages set-repository <镜像URL>` 后复跑 | 编译 rc=0 |
| 1.3 | `pdflatex` 下 `<…>` 占位渲染成 `¡ ¿` | 字体编码对 `<` `>` 的处理 | 属占位现象；要干净空跑就把占位临时换 `TBD`；中文文档一律用 **xelatex** | PDF 目视 |
| 1.4 | PDF 出现 tofu（如 `＜ ￿￿1 ＞`） | **数学模式里写了中文** | 数学模式只用 ASCII（`$\mathrm{sym}_N$`），单位列移出数学模式（`符号表.tex` 已内置该条） | 扫 U+FFFD 计数 = 0 |
| 1.5 | 编译 rc=0 但结果不对 | 仅看返回码不够 | 同时断言 log 含 `Output written on` 且无 `Fatal error`（smoke_chain M7c 口径） | 断言直出 |

## 2 · 模板库 / venv 线

| # | 现象 | 根因 | 处置 | 复验 |
|---|---|---|---|---|
| 2.1 | 模板在系统 Python 下报缺包（sklearn/statsmodels/pulp 等） | **venv 是唯一全通环境**（`<venv>`）；系统 Python 只有通用包 | 一律用 venv 跑：`smoke_all.py` 已强制「优先 venv、否则回退」；手工运行用 `<venv>/Scripts/python.exe` | 35/35 rc=0 |
| 2.2 | 个别模板慢（arima ≈9.5s） | 模型本身重 | 冒烟超时给足（默认 120s/件）；不要因慢判 FAIL | 计时列目视 |
| 2.3 | venv 缺包时想装 | 依赖冻结纪律 | **不装**——报告缺件由人裁定；依赖变更走 requirements.txt 单独批 | 冻结清单对照 |

## 3 · 图件线

| # | 现象 | 根因 | 处置 | 复验 |
|---|---|---|---|---|
| 3.1 | 只出 PNG，没有 PDF/SVG | 混用了 plot_style **v1** 的 `save_fig`（单图）——v2 的三格式出口是 `save_pub` | 用 v2 `save_pub`（figkit 样例已别名 `save_fig = save_pub`） | `_out/` 三格式计数 |
| 3.2 | 图被 workflows/08 判「双 Y 轴」违规 | 多量纲叠一轴 | 分面板，或单位写进刻度标签（figkit demo1/fig3 做法） | 自查表勾选 |
| 3.3 | 黑白打印/色盲下两系列分不清 | ΔL 亮度差过小 | 跑 `utils/figkit/gray_cb_check.py`：ΔL<0.1 报警；叠加线型/标记/斜纹编码（WCAG 相对亮度，口径见 docstring） | 灰度/色盲预览目视 |
| 3.4 | 中文变方框 | 缺中文字形 | 轴标签英文最稳；或依赖字体探测回退（style 系列） | 出图无 CJK 告警 |
