# 图注模板（E-M6 · 图注四要素骨架）

> **用途 / Purpose**：给每张进论文的图配一段自解释图注——只看图不看正文也能读懂；同时统一国赛/美赛两种语言的写法。
> **对应工作流 / Workflow**：`workflows/07-论文撰写.md` §图表规范；`references/图件管线.md`（Figure Contract 四步 / 交付三闸）；工具 `templates-library/utils/plot_style.py` + `figcheck.py`
> **门禁指针 / Gates**：`Euler-ENGINE.md` §1 **E-M6**（图件车间）——PNG+PDF+SVG + **图注齐**；三闸（audit_fig / figcheck / vision；无 vision 则双闸 + 人检）；§3「图件」行
> **降级 / Fallback**：双闸 + 人检（vision 不可用时）
> **填写时机**：做图时与图同批产出（写在绘图脚本头部注释里），装配论文时直接复制

---

## 1 · 图注四要素（骨架）

> **口径来源**：本四要素是 E-M6 门禁「图注齐」的可填骨架，逐条对齐 `workflows/07` §图表规范 与 `图件管线.md` §1 Figure Contract（已列出的条款，不新增判据）。

| # | 要素 | 要求 | 出处（口径） |
|---|---|---|---|
| ① | **编号 + 位置** | 「图 N」连续编号；**图题在图下方**；正文必须有引用（「如图 N 所示」） | `workflows/07` §图表规范 |
| ② | **说明句（自解释）** | 一句话说清：画的是什么对象、在什么条件/参数下、用哪种数据处理；看图不看正文能懂 | `workflows/07` §图表规范「图表能自解释」 |
| ③ | **读图要素与单位** | 图例含义、坐标轴标签 + 单位、误差棒/显著性标记；**措辞与符号表一致**；灰度可区分 | `workflows/07` §图表规范 + §格式细节 |
| ④ | **结论指向 + 来源** | 该图支撑的结论（带数字或趋势）；数据来源与工况（附件 X / 卡号 RC-N / 参数取值） | `图件管线.md` §1（核心结论一句话）+ `_SHARED.md` §8 溯源追踪 |

### 1.1 中文骨架（国赛 · 图注在图下方）

```text
图 <N>  <对象> 在 <条件/参数> 下的 <量> 与 <量> 关系
（panel a：<该面板的独特证据>；panel b：<…>）
数据来源：<附件 X / 复现卡 RC-<N> 产物 <文件名>>；<参数取值>；误差棒为 <标准差/置信区间>。
读图：<怎么读（横轴/纵轴/颜色/线型含义）>；结论：<一句话带数字的结论>。
```

### 1.2 英文骨架（美赛 · 图注在图下方）

```text
Figure <N>. <Quantity A> and <Quantity B> as functions of <variable> under <conditions>.
(Panel a: <unique evidence>; Panel b: <unique evidence>.)
Data: <source (attachment/artifact/RC-N)>; <parameter value>; error bars denote <SD/95% CI>.
Interpretation: <one-sentence takeaway with a number>.
```

> 美赛图注行文注意去 AI 味：`notably/crucially/intriguingly/remarkably` 全文 0 次；em dash 全文 ≤2（`de-ai-writing.md` §五）。

## 2 · 示例占位（替换为本题内容）

```text
图 1  不同 <参数> 下 <目标量> 的变化曲线
（panel a：<单参数扫描 ±20%>；panel b：<双参数热图>）
数据来源：复现卡 RC-1 产物 metrics.json；<参数> 基准值 <值>；误差棒为 5 次重跑标准差。
读图：横轴为 <参数>（<单位>），纵轴为 <目标量>（<单位>），实线/虚线分别对应 <方案 A>/<方案 B>；
结论：<参数> 在 <lo>–<hi> 区间内 <目标量> 变化 <x.x>%，<方案 A> 始终优于 <方案 B> <y.y>%。
```

```text
Figure 2. Optimal <decision> and its sensitivity to <parameter>.
(Panel a: baseline vs. improved solution; Panel b: OAT tornado across three parameters.)
Data: RC-2 artifacts (solution.csv, sensitivity.json); <parameter> = <value>; error bars denote 95% CI over 5 runs.
Interpretation: <decision> reduces <target> by <x.x>% relative to the baseline, and the ranking holds for <parameter> within ±<z>%.
```

## 3 · 与做图/质检流程的衔接

| 步 | 动作 | 出口 |
|---|---|---|
| 1 | 做图前写 **Figure Contract** 四行（结论一句话/逐 panel 证据/图原型/审稿风险）贴在绘图脚本头部 | 无独立证据的 panel 删除（`图件管线.md` §1） |
| 2 | 画布物理尺寸 = 论文实际插入宽度（国赛正文 15.5–16 cm，栏宽 13 cm） | 纸上字号不打折 |
| 3 | 图注按 §1 骨架随图产出（与图同批，避免事后补写漏要素） | 四要素齐 |
| 4 | 闸 1 `audit_fig(fig, insert_cm=…)` | 字号 ≥7.5pt，全过 |
| 5 | 闸 2 `python utils/figcheck.py <图.png>` | 宽 ≥800px 或 DPI ≥150；exit 0 |
| 6 | 闸 3 主模型 vision 逐字转写复核 | 全对、无 tofu/越界/重叠 |
| 7 | `save_pub(fig, "assets/图N-<名>")` 出 PNG+PDF+SVG | 三格式齐；PDF 进 LaTeX |
| 8 | 论文装配时复制图注 + 检查正文引用句 | 无孤图；与符号表措辞一致 |

> PPT 制图（机理示意图/装置图/流程图）：以「slide 尺寸 = 插入尺寸」保证字号，去阴影，过 figcheck + vision 两闸（不适用 audit_fig）——`图件管线.md` §6.5。

## 4 · 常见图注缺陷（改前先查表）

| 缺陷 | 表现 | 修正 |
|---|---|---|
| 无结论 | 图注只有「…示意图/对比图」 | 补要素 ④：一句话带数字的结论 |
| 单位缺失 | 轴标签无单位、数值无单位 | 补要素 ③；`add_units()` 统一加 |
| 符号不一致 | 图注用词与符号表/正文不同（模型/算法/方案混用） | 统一到一个词（`de-ai-writing.md` §8） |
| 条件缺失 | 没说清在什么参数/工况下的结果 | 补要素 ②（条件/参数/处理） |
| 来源缺失 | 没说数据来路 | 补要素 ④（附件号 / RC 卡号 / 外部来源版本） |
| 孤图 | 正文没有「如图 N 所示」 | 正文补引用或删图 |
| 图题位置错 | 图题在图上方 / 表题在表下方 | 图题在图下方、表题在表上方（`workflows/07`） |
| 多面板无标签 | panel a/b 未标或未在图注解释 | 图标 (a)(b) + 图注逐 panel 写独特证据 |
| 灰度不可读 | 打印后曲线分不清 | `next_style()` 的「颜色×线型×标记」组合；`gray_cb_check` |

## 5 · 自检

- [ ] 每张图有编号 + 图注，**图题在图下方**，正文有引用
- [ ] 四要素齐（编号位置 / 说明句 / 读图要素与单位 / 结论指向与来源）
- [ ] 图注措辞与符号表一致（同一概念同一词）
- [ ] 单位与误差棒已注明；灰度打印可区分
- [ ] 语言正确（国赛中文 / 美赛英文）；英文无 AI 高频词与 em dash 滥用
- [ ] 三闸（或双闸 + 人检）已过并留证
- [ ] 图注与复现卡产物对应（可回溯到 artifact）
- [ ] Figure Contract 四行已写在绘图脚本头部
