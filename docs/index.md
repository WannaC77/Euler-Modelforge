# Euler-Modelforge

数学建模竞赛**工作流引擎**（MCM/ICM · CUMCM）——把备赛与解题过程做成**可复现、时间盒、门禁驱动**的流水线：读题定位 → 建模选型 → 求解 → 检验 → 论文装配 → 提交合规，全链有硬判据。

## 这个仓里有什么

| 板块 | 内容 |
|---|---|
| `workflows/` | 11 篇流程正本（备赛管理 → 选题读题 → 建模求解 → 检验敏感性 → 论文提交） |
| `modules/` | 10 个能力模块 + 底座（读题定位 / 假设符号 / 选型 / 求解工坊 / 检验台 / 图件车间 / 论文装配 / 合规闸 / 校准锚 / 编排器） |
| `templates-library/` | 35 个可运行求解模板（优化 / 预测 / 评价 / 统计学习 / 微分方程 / 图论 / 仿真 / 智能算法）+ figkit 图件车间 |
| `tools/` | `env_check`（环境档位 T0/T1/T2）与 `smoke_chain`（端到端冒烟 + 黄金数值断言） |
| `scripts/` | 提交门禁：`precheck_paper`（论文预检）· `verify_manifest`（文档-磁盘一致性） |
| `examples/` | 3 个 5 分钟上手示例（全合成数据） |

## 快速开始

```bash
pip install euler-modelforge[all]

```

[5 分钟上手](quickstart.md) · [运行示例](examples.md) · [工具索引](tools.md)

## 设计原则（摘要）

- **时间盒**：每一阶段给出预算与「到点即收」规则，避免论文周通宵。
- **门禁驱动**：冒烟、敏感性、合规检查都由**可失败**的脚本判定（退出码契约：`0` 通过 · `1` 失败 · `2` 用法 · `3` 依赖缺失未执行）。
- **可复现**：模板随包分发、合成数据内置、黄金数值断言随测试链真跑。
