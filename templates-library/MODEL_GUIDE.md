# 模型速查指南（比赛时先查这个）

> 遇到问题 → 查题型 → 点开对应模板 → 改参数 → 跑。
> 所有模板在 `<venv>` 环境可独立运行。

## 第一步：判断题目类型

| 题目特征 | 题型 | 优先模板 |
|---------|------|---------|
| 求最大/最小/最优方案、排班、调度、选址 | **优化** | 01-优化/* |
| 预测未来值/趋势、数据外推 | **预测** | 02-预测/* |
| 打分、排序、选优、评估方案 | **评价** | 03-评价/* |
| 给一堆数据找规律/分类/找关系 | **统计ML** | 04-统计与机器学习/* |
| 随时间连续演化、动力学、传播 | **微分方程** | 05-微分方程/* |
| 网络、路径、连接、流程 | **图论** | 06-图论/* |
| 随机性、复杂系统、无解析解 | **仿真** | 07-仿真/* |
| 难解的优化（非线性/组合） | **智能算法** | 08-智能算法/* |

## 详细速查

### 01-优化
| 场景 | 模板 | 要点 |
|------|------|------|
| 线性目标+线性约束 | `lp.py` | INTEGER=True 切整数规划 |
| 产地→销地调运 | `transportation.py` | 产销不平衡自动加虚拟地 |
| 任务×人 一对一最优匹配 | `assignment.py` | 匈牙利算法 |
| 容量/资源分配、选与不选 | `dp_knapsack.py` | 0-1 背包 DP |
| 非线性目标/约束 | `nlp.py` | scipy minimize |
| 多目标权衡 | `multiobjective.py` | 加权法+Pareto 图 |

### 02-预测
| 场景 | 模板 | 要点 |
|------|------|------|
| 小样本(≥4)近指数增长 | `grey_gm11.py` | 后验差 C<0.35 优 |
| 长历史单变量含趋势季节 | `arima.py` / `exp_smoothing.py` | AIC 自动定阶 |
| 多自变量影响预测 | `linear_regression.py` | 看 p 值选显著变量 |
| 状态转移/占比演化 | `markov_chain.py` | 稳态分布 |

### 03-评价
| 场景 | 模板 | 要点 |
|------|------|------|
| 主观判断矩阵评价 | `ahp.py` | CR<0.1 必须 |
| 客观数据多指标排序 | `topsis_entropy.py` | 熵权客观+TOPSIS |
| 指标关联度分析/小样本选优 | `grey_relation.py` | 理想参考自动构造 |
| 评语模糊划分 | `fuzzy_eval.py` | 隶属度矩阵 |
| 多投入多产出效率 | `dea.py` | CCR 效率 0-1 |

### 04-统计ML
| 场景 | 模板 | 要点 |
|------|------|------|
| 数据清洗准备 | `data_preprocess.py` | 缺失/异常/标准化 |
| 差异显著性 | `hypothesis_tests.py` | 先正态再选检验 |
| 有标签分类/回归 | `supervised_ml.py` | RF 提精度 |
| 无标签找结构 | `kmeans_pca.py` | PCA 先降维看 |

### 05-微分方程
| 场景 | 模板 | 要点 |
|------|------|------|
| 传染病/传播 | `sir.py` / `seir.py` | 敏感性必做 |
| 捕食/竞争/任意 ODE | `ode_general.py` | 只改右端函数 |
| 增长趋饱和 | `logistic_growth.py` | 拟合 r,K |

### 06-图论
| 场景 | 模板 | 要点 |
|------|------|------|
| 最短路径/连通成本 | `shortest_path_mst.py` | 最短路+MST |
| 网络输送上限/瓶颈 | `max_flow.py` | 最大流=最小割 |
| 工程工期排程 | `critical_path.py` | 时差=0 是关键 |
| 网络结构分析 | `network_metrics.py` | 中心性/社区 |

### 07-仿真
| 场景 | 模板 | 要点 |
|------|------|------|
| 随机概率/数值积分 | `monte_carlo.py` | 收敛看样本量 |
| 服务台配置 | `queue_mmc.py` | M/M/c 决策 |
| 离散时空演化 | `cellular_automata.py` | 交通流/扩散 |

### 08-智能算法
| 场景 | 模板 | 要点 |
|------|------|------|
| 通用黑箱优化 | `ga.py` / `pso.py` | 收敛判断 |
| 组合优化(路径/调度) | `sa.py` / `aco_tsp.py` | TSP 等 |

## 万能工作流（任何题都能套）

```
1. data_preprocess → 数据就绪
2. 判断题型 → 选主模型（做深）→ 跑出结果
3. 模型检验: 敏感性分析 (utils/sensitivity.py) ← 论文必备
4. 图表: utils/plot_style.py 论文级输出
5. 表格: utils/latex_table.py 直接贴进 LaTeX
```

## 高频坑（评委扣分点）

| 坑 | 解法 |
|----|------|
| AHP 忘一致性检验 | CR>0.1 重填矩阵 |
| 灰色预测数据波动大还硬用 | 先看后验差 C |
| ARIMA 数据不平稳 | auto_arima 自动差分 |
| 模型堆砌每个都浅 | 1-2 个主模型做深+敏感性 |
| 图表没单位/不解释 | plot_style.add_units |
| 随机算法结果不可复现 | 固定 np.random.seed |
